#  Udemy Website Clone (HTML & CSS Project)

##  Project Overview

This project is a **static clone of the Udemy website** created using **HTML and CSS**.
The objective of this project is to replicate the layout and design of the Udemy homepage while practicing front-end development concepts like semantic HTML, Flexbox, Grid, and responsive design.

This project was built as part of **Week 1 Front-End Development Practice**.

---

##  Features

* 🔹 Semantic HTML structure
* 🔹 Responsive design using **Flexbox & CSS Grid**
* 🔹 Udemy-style navigation bar with logo and search bar
* 🔹 Menu bar similar to Udemy
* 🔹 Recommended courses section with images & details
* 🔹 Recommended topics section with input box
* 🔹 Popular courses section sorted by ratings
* 🔹 Fully designed footer with links & copyright
* 🔹 Mobile-friendly responsive layout

---

##  Technologies Used

* **HTML5** – For webpage structure
* **CSS3** – For styling and layout
* **Flexbox** – For alignment and responsiveness
* **CSS Grid** – For structured layout
